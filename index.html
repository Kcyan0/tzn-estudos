Criador de Briefing

Cole as anotações do lead (texto corrido, transcrição de call, print da conversa colado como texto) — a IA monta o relatório no formato padrão. Roda direto no seu navegador, com a sua própria chave da Anthropic — nada passa pelo nosso servidor.

🔑 Chave de API salva neste navegador

Gere a sua em console.anthropic.com → Settings → API Keys. Fica salva só neste navegador (nunca é enviada pra nenhum servidor nosso) — cada SDR usa a própria chave e paga o próprio uso.

Quanto mais contexto, mais preciso o relatório — mas funciona mesmo com anotações soltas.
